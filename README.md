# Física Computacional 1: 

Repositorio oficial del **Física Computacional 1** para Física en la **Institución Universitaria ITM**.

En este espacio se encuentran alojados los materiales de clase, cuadernos de Jupyter y códigos fuente utilizados a lo largo del semestre.

---

## 📁 Estructura del Repositorio

- `Clases/`: Notas teóricas, diapositivas y guías del curso.
- `Codigo/`: Cuadernos interactivos de Jupyter (`.ipynb`) explicativos, algoritmos y scripts complementarios en Python (`.py`).
- `Tareas/`: Enunciados de talleres y entregables para el curso.
